# AI-Powered Code Explanation and Debugging Assistant

An LLM-powered programming assistant that helps users understand,
debug, optimize, review, and analyze source code.

## Features

- Code explanation
- Bug detection
- Debugging assistance
- Code optimization
- Complexity analysis
- Code review
- Code conversion
- Python syntax checking
- RAG-based programming knowledge retrieval
- Beginner-friendly explanations

## Technologies

- Python
- FastAPI
- Ollama
- Llama 3.2
- Scikit-learn
- TF-IDF
- HTML
- CSS
- JavaScript

## Architecture

User
↓
Frontend
↓
FastAPI Backend
↓
Code Processing
↓
RAG Retrieval
↓
LLM
↓
AI Generated Explanation
↓
Frontend
